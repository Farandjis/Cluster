## <a name="I"></a>I - Introduction

The following document aims to test the different pages of the static HTML site created. Each page will be tested individually to check if it meets the screen size requirements, and if it aligns with the chosen mockup in terms of design and functionality. Furthermore, the HTML pages must comply with accessibility standards using the Wave tool and the W3C HTML validator installed on the machines.<br>

## <a name="II"></a>II - Test Procedure Description

The application to be developed requires creating mockups to visualize and describe what the final website should contain and look like. Afterward, we will rely on the proposed mockups to build the final website, but first, the HTML pages must be operational and error-free to avoid potential issues during development.
For each HTML page created, we will compare it with the selected mockup. This includes checking whether the elements are placed in the same location as in the mockup, whether they can be displayed on any computer screen, and if they are validated and checked using the W3C HTML and Wave tools.<br>
